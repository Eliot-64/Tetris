- `tetris1.mp3` for the main looping game music.
- `tetris2.mp3` for the level 10 cinematic music.
- `line-clear.mp3` for completed line clears.
- `rotate.mp3` for successful rotations.
- `hard-drop.mp3` for instant piece drops.
